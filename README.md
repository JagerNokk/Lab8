# ЛР 8. Линейная регрессия: цена аренды квартир в Астане

Кейс: сервис объявлений хочет подсказывать арендодателю цену и объяснять, какие
характеристики квартиры влияют на неё сильнее всего. Цель — `price` (тг в месяц).

## Данные

`data/astana_rent_clean.csv` — 600 очищенных объявлений (результат ЛР 7, столбец `area_raw`
переименован в `area`). Пропуски в `area`, `floor`, `year`, `furniture` оставлены намеренно:
их заполняет Pipeline, чтобы не было утечки данных.

**Отличие от методички:** в этом файле нет признака `dist_center`. В шагах 6 и 7 вместо него
использованы `year` (бины) и `area` (полином), поэтому числа отличаются от эталонных.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt jupyter
python src/train.py        # пишет metrics.json и models/model.joblib
```

`cv_r2` — средний R² на 5 фолдах обучающей выборки. Тест для выбора эксперимента не используется.

## Эксперименты

| Ветка | Параметры | cv_r2 | test_r2 | test_rmse | Решение |
|-------------|----------------------------|--------|--------|--------|-------------|
| main (база) | linear | 0.8549 | 0.9095 | 28 743 | базовая |
| exp/ridge | ridge, alpha=3 | 0.8554 | 0.9101 | 28 662 | слита, v1.0 |
| exp/bins | linear, бины `year` (8) | 0.8521 | 0.9027 | 29 811 | не слита |

Сравнение веток: `git diff main exp/ridge -- metrics.json`.

## Выводы

- Базовая линейная модель объясняет около 85 % разброса цен на кросс-валидации (на тесте 0,91);
  типичная ошибка на тесте — около 29 тыс. тг (≈ 21,6 тыс. по MAE).
- Самое важное для цены — район (падение R² без него 0,137) и площадь (0,089); год и число комнат
  заметно слабее, мебель, этаж и этажность почти ничего не добавляют.
- Ridge с α = 3 улучшил cv R² всего на 0,0005 — это меньше разброса между фолдами (≈ 0,04), поэтому
  выигрыш скорее формальный. Ветка слита по правилу «сливаем то, что улучшило `cv_r2`».
- Бины по `year` качество не улучшили (0,852): сильной нелинейности в имеющихся признаках нет.
- Lasso на этих данных обнуляет 3 веса из 12 (`district_Сарыарка`, `furniture_yes`, `floors`),
  качество не меняется: при 450 объектах и 12 признаках переобучения практически нет.
